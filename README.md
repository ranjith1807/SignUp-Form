ign-Up Form

A modern, responsive, and interactive Sign-Up Form built with frontend web technologies. This project focuses on clean user interface design and client-side form validation to ensure a seamless user experience during registration.

🌍 **Live Demo:** [View Project Here](https://ranjith1807.github.io/SignUp-Form/)

## 🚀 Features

* **Responsive Design:** Fully responsive layout that looks great on desktops, tablets, and mobile devices.
* **Form Validation:** Real-time client-side validation to ensure inputs (like email format and password strength) are correct before submission.
* **Interactive UI:** Smooth hover states, focus outlines, and error/success message displays.
* **Clean Code:** Semantic HTML and well-structured CSS/JavaScript.

## 🛠️ Technologies Used

* **HTML5:** Semantic layout and form structuring.
* **CSS3:** Custom styling, Flexbox/Grid for layout, and media queries for responsiveness.
* **JavaScript:** DOM manipulation, event listeners, and logic for input validation.
